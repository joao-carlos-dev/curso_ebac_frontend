# Imbituba

## Introdução

Este projeto é uma página web informativa sobre a cidade de Imbituba, localizada no sul de Santa Catarina. A página destaca as belezas naturais da cidade,
incluindo suas praias, atrações turísticas e informações sobre a observação de baleias francas. Utiliza Bootstrap para o layout responsivo e um carrossel para exibir imagens das praias.

## Tecnologias Utilizadas

* **HTML5:** Estrutura da página web.
* **CSS:** Estilização da página com `main.css`.
* **Bootstrap 5:** Framework CSS para layout responsivo e componentes.
* **Bootstrap Icons:** Biblioteca de ícones para melhorar a interface.
* **Google Fonts:** Utilização de fontes personalizadas.
* **JavaScript (Bootstrap):** Interatividade e funcionalidades dinâmicas dos componentes Bootstrap.
* **Imagens:** Utilização de imagens para banners, fotos das praias e atrações.

## Funcionalidades

* **Cabeçalho com Navegação:** Menu de navegação com links para seções da página (Sobre, Praias, Outras Atrações, Localização).
* **Carrossel de Imagens:** Exibe imagens das praias de Imbituba.
* **Seção "Sobre Imbituba":** Apresenta informações gerais sobre a cidade, incluindo sua história e atrações principais.
* **Seção "Praias":** Exibe informações detalhadas sobre as principais praias de Imbituba, utilizando abas para navegação entre elas.
* **Seção "Outras Atrações":** Apresenta outras atrações turísticas da cidade, como a observação de baleias francas e a Casa Açoriana.
* **Seção "Localização":** Exibe um mapa da cidade de Imbituba.
* **Design Responsivo:** A página se adapta a diferentes tamanhos de tela graças ao Bootstrap.
